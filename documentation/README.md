# Documentation

Cette documentation accompagne le prototype Clone Relief. Le README à la
racine reste le point d’entrée du projet et donne les commandes rapides.

## Documents

- [HANDOFF.md](HANDOFF.md) — contexte du projet, état actuel et prochaine étape.
- [SPECIFICATIONS.md](SPECIFICATIONS.md) — objectif produit, exigences et critères d’acceptation.
- [DEVELOPMENT.md](DEVELOPMENT.md) — environnement, architecture mathématique M1, commandes et limites.
- [USER_GUIDE.md](USER_GUIDE.md) — installation macOS, schéma du panneau, parcours illustré et validation sur copie.
- [PRINT_QUALIFICATION.md](PRINT_QUALIFICATION.md) — protocole de qualification utilisant notamment le 3D Print Toolbox, le trancheur et une impression réelle.
- [Exemple avant/après](examples/README.md) — comparaison visuelle synthétique, détails rapprochés et scène Blender reproductible.
