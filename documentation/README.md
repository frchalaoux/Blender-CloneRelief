# Documentation

[Français](README.md) · [English](README.en.md)

La documentation française reste la référence. Les fichiers anglais traduisent
son état actuel et seront actualisés sur demande.

Cette documentation accompagne le prototype Clone Relief. Le README à la
racine reste le point d’entrée du projet et donne les commandes rapides.
